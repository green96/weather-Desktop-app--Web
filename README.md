A Lightweight Weather App for Windows

Why should a simple weather app need 1+ GB of RAM?

Windows 11’s built-in Weather experience can feel surprisingly heavy for something that should just show you the weather (https://www.notebookcheck.net/Windows-11-s-built-in-Weather-app-wastes-more-than...).

So I’m building an open-source desktop weather app focused on one thing:

Weather without the bloat.

Lightweight | Built for desktop | Clean and simple UI | Open source | Fast startup |Designed to use minimal system resources

No unnecessary features. No bloated background processes. Just open the app, check the weather, and get on with your day.

If a weather app can be lightweight, why shouldn’t it be?

The source code will be available for everyone to inspect, improve, and contribute to.
